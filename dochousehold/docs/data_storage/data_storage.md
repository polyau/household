Сущности проектирумой ИС с атрибутами и характером взаимодействия с данными:

|Сущность|Атрибуты (ключевые)|Тип данных|
|-|-|-|
|Пользователь (User)|user_id, full_name, email, password_hash, created_at|Транзакционные|
|Пространство (Space)|space_id, name, owner_id, invite_code|Транзакционные|
|Задача (Task)|task_id, space_id, title, assignee_id, status, deadline, add_to_calendar, recurrence, created_at|Транзакционные|
|Покупка (ShoppingItem)|shopping_item_id, space_id, title, category, status, created_at|Транзакционные|
|Событие календаря (Event)|event_id, space_id, title, starts_at, reminder_offset, participants, created_at|Транзакционные|
|Уведомление (Notification)|id, user_id, type, entity_id, status, created_at|Событийные|
|Логи (Logs)|id, timestamp, level, event_type, user_id, space_id, entity_id, request_id, payload|Аналитические|

Участники пространств создают и изменяют задачи, покупки и события в рамках своих пространств. Администраторы дополнительно управляют настройками пространства, участниками и кодом приглашения.

Связи между сущностями:
- Пользователь и Пространство связаны М:М: один пользователь может состоять в нескольких пространствах, а одно пространство может включать нескольких пользователей. В рамках пространства для пользователя фиксируется его роль.
- Пространство и Задача связаны 1:М: в одном пространстве может быть создано много задач, каждая задача относится только к одному пространству.
- Пользователь и Задача связаны через назначение исполнителя 1:М: одна задача может иметь одного исполнителя из числа участников пространства, при этом один пользователь может быть исполнителем многих задач. Если исполнитель не выбран, задача считается общей для пространства.
- Пространство и Покупка связаны 1:М: в одном пространстве может быть много позиций списка покупок, каждая позиция относится только к одному пространству.
- Пространство и Событие календаря связаны 1:М: в одном пространстве может быть много событий календаря, каждое событие относится только к одному пространству.
- Пользователь и Событие календаря связаны М:М: в одном событии может участвовать несколько пользователей, а один пользователь может быть участником нескольких событий.
- Уведомление связано с пользователем М:1: одно уведомление адресовано одному пользователю, а пользователь может получать много уведомлений. Уведомление также связано с объектом, по которому оно создано, например, с задачей или событием календаря.
- Логи связаны с действиями пользователей и объектами системы: запись лога может содержать user_id, space_id и entity_id, чтобы можно было определить, какой пользователь, в каком пространстве и над какой сущностью выполнил действие.
